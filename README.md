# Trabalho de Programação Orientada a Objetos (POO) - 2024/2025

## 📌 Tema
**Sistema de Gestão de Alojamentos Turísticos**  
Este projeto tem como objetivo desenvolver uma aplicação em C# para a gestão de alojamentos turísticos. A aplicação permite gerir reservas, clientes e alojamentos.

## 👨‍💻 Autor
- Tiago Nunes Ferreira – 27980

## 🎯 Objetivos
- Aplicar os princípios fundamentais da programação orientada a objetos (POO).
- Utilizar herança, polimorfismo, encapsulamento e tratamento de exceções.
- Organizar o código de forma modular e reutilizável.
- Criar uma aplicação funcional de consola.
- Gerar documentação automática com Doxygen.

## 🧱 Fases do Projeto

### Fase 1
- Análise do problema e levantamento de requisitos.
- Modelação UML com as principais entidades do sistema.
- Planeamento da arquitetura da aplicação.
- Implementação das estruturas base (classes, enums, menus, etc).

### Fase 2
- Implementação das funcionalidades principais do sistema.
- Leitura e escrita de dados em ficheiros.
- Gestão de reservas, clientes e alojamentos.
- Documentação com Doxygen.

## 🧩 Funcionalidades
- Registo e listagem de alojamentos e clientes.
- Criação e gestão de reservas.
- Cancelamento de reservas.
- Remoção de alojamento ou cliente.
- Armazenamento de dados em ficheiros.
- Geração de documentação automática.
